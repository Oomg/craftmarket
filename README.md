# CraftMarket

Наскрізний навчальний проєкт курсу «Веб-дизайн та веб-програмування (React)».

Стек: React 19 + Vite.

## Виконані лабораторні роботи

- **ЛР1** — розгортання проєкту, ESLint, Prettier, структура тек, порт 4000
- **ЛР2** — компонент ProductCard + PropTypes + BEM

## Запуск

npm install
npm run dev
